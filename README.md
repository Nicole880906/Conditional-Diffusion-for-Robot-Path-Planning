# Robot Path Planning: Diffusion Models vs. A* 🤖

This repository implements and compares state-of-the-art path planning algorithms for autonomous robots. The project evaluates the efficiency and smoothness of **Diffusion-based Generative Models** against classical **A* search** and **B-Spline** interpolation in complex 2D occupancy grids.

## 🚀 Project Overview
The core of this research is to navigate a robot from a start configuration to a goal while avoiding obstacles. We explore how generative models can learn the underlying distribution of valid paths to produce trajectories that are often smoother and more kinematically feasible than those generated by traditional grid-based solvers.

## 🛠 Features
* **Map Generation:** Automated creation of occupancy grids and obstacle maps for training and testing.
* **A* Pathfinding:** A robust implementation of the A* algorithm used as a baseline for path existence and shortest-path metrics.
* **B-Spline Smoothing:** Post-processing of discrete paths to ensure smooth, continuous robot motion.
* **Diffusion Models:** A deep generative approach to trajectory synthesis, "denoising" random noise into a valid, collision-free trajectory.
* **Performance Analytics:** Comprehensive evaluation scripts to measure success rates and endpoint connectivity.

## ⚙️ Requirements
 - Python 3.8+
 - PyTorch (for Diffusion Models)
 - NumPy & Matplotlib
 - SciPy (for B-Spline interpolation)
